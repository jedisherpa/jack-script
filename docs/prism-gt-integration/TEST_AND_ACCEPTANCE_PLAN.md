## Negative and Security Checks
- **API Key Leakage:** Ensure that error responses generated by `lib/errors.ts` do not contain stack traces or environment variables when operating in production mode.
- **Cross-Tenant Isolation:** Verify that requests authenticated with a token for Campaign A cannot access or modify resources belonging to Campaign B.
- **Local-First Resilience:** Confirm that the desktop application (`npm run desktop:dev`) continues to function using SQLite when network access to Prism GT services is simulated as down.
